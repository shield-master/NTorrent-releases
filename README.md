# NTorrent Releases

This repository hosts **binary installer releases only** for NTorrent — no source
code. NTorrent's source lives in a private repository; this repo exists purely so
the in-app updater and end users have a public place to fetch installers from.

- Latest installer: see [Releases](../../releases/latest)
- Version manifest used by the in-app updater: [`versions.json`](versions.json)
